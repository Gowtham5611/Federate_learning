## 3. Methodological Integrity & Research Verification

1. **Zero Data Leakage:**
   * Temporal cuts strictly precede validation and testing.
   * Causal graph features evaluate edges $\le t$.
   * Preprocessing parameters (means, standard deviations, categorical vocabularies) are fitted strictly on `train` splits and frozen.
2. **Model Integrity:**
   * Frozen checkpoints (`HI-Small` LSTM, `LI-Medium` BiLSTM) have fixed decision thresholds (`0.337784` and `0.238483`) that cannot be overwritten by dynamic training.
   * Mode B custom model training writes exclusively to `results/dynamic_models/` without modifying IBM models.
3. **Evaluation Protocol:**
   * Because AML transaction data exhibits severe class imbalance ($0.1\%$ to $0.3\%$ positive prevalence), PR-AUC, Recall@FPR, and False Positive Volume per 10,000 transactions are the primary scientific criteria.
   * Decision thresholds are optimized strictly on validation sets and frozen prior to test evaluation.
4. **Regulatory Honesty:**
   * Federated learning provides data isolation across institutional silos, but formal Differential Privacy requires active gradient clipping and noise injection.
   * Model outputs represent continuous probabilistic risk indicators requiring human investigator adjudication, not automated criminal verdicts.
   * Generated investigation exports are explicitly labeled *"Suspicious Activity Investigation Report — Draft"* for internal compliance case management.
